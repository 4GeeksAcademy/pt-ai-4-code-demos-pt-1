# Day 1 - What even is an agent?

A simple **Greeting App** built with Vite, TypeScript, and Tailwind CSS. Enter your name, click "Hello!", and get a personalized greeting — all created by an AI agent.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or newer recommended)
- npm (comes with Node.js)

### Install & Run

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev
```

Then open the URL shown in the terminal (typically `http://localhost:5173`) in your browser.

### Other Commands

| Command           | Description                           |
| ----------------- | ------------------------------------- |
| `npm run dev`     | Start the development server          |
| `npm run build`   | Type-check and build for production   |
| `npm run preview` | Preview the production build locally  |

## 🤖 How the Agent Created This Project

This entire project was generated by **GitHub Copilot's AI coding agent** through a series of natural language prompts. Here's how it unfolded:

1. **Project scaffolding** – The agent ran `npm create vite@latest` with the `vanilla-ts` template to bootstrap a Vite + TypeScript project.
2. **Tailwind CSS setup** – The agent installed Tailwind CSS v4 and the `@tailwindcss/vite` plugin, then configured `vite.config.ts` to use it.
3. **UI development** – The agent wrote all the HTML, CSS, and TypeScript code for the greeting app, including the text input, button, and greeting display.
4. **Quality of life** – The agent added a keyboard shortcut so pressing **Enter** in the input field triggers the greeting (just like clicking the button).
5. **Git & publishing** – The agent initialized a Git repository, created commits, and pushed the project to GitHub.

Every decision — from the tech stack to the UI styling to the interactive behavior — was driven by prompts written by the developer and executed autonomously by the agent.
